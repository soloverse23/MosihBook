راهنمای نصب MosiBooks روی ویندوز

۱. روی فایل ZIP راست‌کلیک کنید و Extract All را بزنید.
۲. داخل پوشهٔ بازشده، روی Install-MosiBooks.bat دوبار کلیک کنید.
   اگر هشدار آبی ویندوز آمد: More info و بعد Run anyway.
۳. چند دقیقه صبر کنید تا نصب تمام شود. به اینترنت نیاز دارد.
۴. مرورگر خودش باز می‌شود. یوزر و پسوردی را که به شما داده‌اند وارد کنید.
۵. در صفحهٔ راه‌اندازی، گزینهٔ My Claude subscription را انتخاب کنید.
   اگر Claude Code از قبل روی این سیستم وارد شده باشد، خودش وصل می‌شود.
   اگر نه، Sign in with Claude را بزنید و با حساب Claude خودتان وارد شوید.
۶. برای ساخت تصویر، کلید API خودتان از OpenAI را وارد کنید.

استفادهٔ روزانه: روی آیکن MosiBooks در دسکتاپ دوبار کلیک کنید.
پنجرهٔ کوچک‌شدهٔ MosiBooks در نوار پایین را نبندید؛ با بستن آن برنامه متوقف می‌شود.
کتاب‌ها در پوشهٔ MosiBooks داخل پوشهٔ کاربری شما ذخیره می‌شوند.

به‌روزرسانی: وقتی نسخهٔ جدیدی آماده باشد، با باز کردن MosiBooks پنجره‌ای می‌آید.
دکمهٔ Update now را بزنید و یکی دو دقیقه صبر کنید؛ برنامه خودش بسته، نصب و دوباره باز می‌شود.
کتاب‌ها و تنظیمات شما دست نمی‌خورند.
